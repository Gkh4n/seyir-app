# Seyir

Türkçe odaklı dizi + film kişisel puanlama ve izleme profili.

## v0.1
- Dizi ve film katalogları
- Genel puan / kişisel puan karşılaştırması
- Dizi bölüm puan grafiği
- Favoriler ve izleme listesi
- Kişisel puanların tarayıcıda saklanması
- Profil ve zevk analizi prototipi
- Mobil uyumlu karanlık arayüz

## Sonraki aşama
1. TMDB API ile gerçek yapım, poster, sezon ve bölüm verileri
2. Supabase Auth + kullanıcı profilleri
3. Puanları veritabanında saklama
4. Arkadaş zevk uyumu ve paylaşılabilir profiller
5. Yıllık izleme özeti
